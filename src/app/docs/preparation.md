## Description du projet

Notre projet consiste à créer une application web de gestion de bibliothèque.
Les utilisateurs pourront consulter une liste de livres, rechercher des livres
et voir les détails de chaque ouvrage.

Le projet sera développé avec Next.js et React.

## Objectifs

- Créer une interface moderne et responsive
- Permettre la recherche de livres
- Afficher les détails des livres
- Utiliser une bonne structure de projet
- Acheter des livres
